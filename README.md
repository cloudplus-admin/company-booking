# Бронь компаний

Простой инструмент, чтобы менеджеры брали компании в работу. Без внешних зависимостей (Python 3, SQLite).

Запуск:

    python3 server.py

По умолчанию слушает 127.0.0.1:48610. Порт и адрес задаются переменными PORT и HOST, файл базы - BOOKING_DB.

Тесты:

    python3 -m unittest -v test_server

Авторизации пока нет. Имя менеджера вводится в шапке страницы.
